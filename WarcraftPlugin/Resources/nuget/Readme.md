An open-source Warcraft mod for CS2 featuring a fully-fledged RPG system.

Warcraft 4.2.0 targets .NET 10 and uses CounterStrikeSharp 1.0.381. Server setup requires Metamod:Source 2.0 build 1467 or newer with KHook and the matching CounterStrikeSharp runtime. See the [CounterStrikeSharp installation guide](https://docs.cssharp.dev/docs/guides/getting-started.html).
