Overview

The CS2 Warcraft Mod is a comprehensive RPG plugin that transforms standard Counter-Strike gameplay. Players earn Experience (XP) by defeating enemies and completing objectives. As they level up, they can unlock and upgrade unique racial abilities and purchase powerful magical items from the shop.

Game Mechanics

Experience & Leveling

Earn XP to level up and gain skill points. Max level is 16.

  • Kill: Base XP + Bonuses
  • Headshot: +15% Bonus XP
  • Knife Kill: +25% Bonus XP
  • Level Gap: Bonus XP for killing higher-level players
  • Objectives: XP for Bomb Plant/Defuse, Round Win, Assists

Menu System

Navigate the mod easily with chat commands.

!race or !class - Open Class Selection
!shop or !store - Open Item Shop
!skills or !level - Spend Skill Points
!resetskills - Reset Ability Points
!info - View Player Stats
!ultimate - Use Ultimate Ability (Bind this!)

Database & Persistence

Your progress is safe. The server automatically saves your XP, Level, and Skill distribution for every race.

Data is stored via SQLite in database.db, ensuring fast and reliable access to your stats every time you connect.

Classes & Races

Ranger

A nimble warrior who excels at mobility and traps.

  • Light footed Nimbly perform a dash in midair. Cooldown decreases from 18s to 6s.
  • Ensnare trap Place a trap by throwing a decoy that deals 10-50 damage and snares enemies.
  • Marksman Deal 2-10 bonus damage with scoped weapons.
  • Arrowstorm Ultimate Ping a point to rain arrows for 10s, hurting and slowing foes.

Barbarian

A brute force fighter specializing in close combat and tankiness.

  • Carnage Deal an extra 5-25 damage with shotguns.
  • Battle-Hardened Increase your health by 20-100 HP.
  • Throwing Axe Chance to throw an exploding barrel when firing (3-13% chance).
  • Bloodlust Ultimate For 10s gain infinite ammo, 30% more speed, and constant health regen.

Death Weaver

A master of dark arts who weakens enemies and raises the dead.

  • Cripple 25% chance to slow an enemy for 1.5-3.5 seconds.
  • Unholy Frenzy 25% chance to deal 10-50% bonus damage.
  • Necromancer Master 65-85% chance to spawn with an assault rifle (AK47/M4A1).
  • Raise Skeleton Ultimate 80% chance to revive a fallen ally. Cooldown: 60s.

Dwarf Engineer

A builder who constructs defenses and mines for resources.

  • Build Allows you to build structures using the builder tool (3-15 charges).
  • Pickaxe 6-30% chance to find grenades when stabbing surfaces.
  • Stone Skin Increase armor by 20-100.
  • Goldrush! Ultimate Gain 1000 HP and a speed boost for 10s.

Hammerstorm

A powerful warrior with stunning attacks and cleaving strikes.

Mage

A spellcaster who controls fire and ice.

  • Fireball Infuses molotovs with fire magic, causing a huge explosion (40-200 dmg).
  • Ice Beam 5-25% chance to freeze enemies in place.
  • Mana Shield Regenerates 1 armor every 5-1s.
  • Arcane Dash Ultimate Dash rapidly in the direction you're aiming.

Necromancer

A summoner who drains life and commands the undead.

  • Life Drain Heal for 6-30% of damage dealt.

A holy warrior who heals allies and smites foes.

Rogue

A stealthy assassin who strikes from the shadows.

Sacred Warrior

A berserker who gains power as they lose health.

  • Life Break Ultimate Sacrifice 20% HP to deal 40% of victim's max HP as damage.

Shadowblade

An elusive fighter who teleports and evades attacks.

  • Shadowstep 4-20% chance to teleport behind the attacker when taking damage.
  • Evasion 6-30% chance to completely dodge incoming damage.
  • Venom Strike Attacks poison enemies, dealing 1-5 DPS for 4s.

Shapeshifter

A master of disguise who can mimic enemies and objects.

Silent Assassin

A small, fast killer who specializes in knife combat.

  • Shrink Reduce model size by 15-35%.
  • Lightweight Increase speed and reduce gravity.
  • Assassin's Blade 40% chance to add bonus knife damage.
  • Ghost Walk Ultimate Completely invisible for 3 seconds.

Tinker

A tech specialist who deploys drones and traps.

  • Attack Drone Deploy a drone that attacks nearby enemies.
  • Spare Parts 4-20% chance to not lose ammo when firing.
  • Spring Trap Deploy a trap which launches players into the air.
  • Drone Swarm Ultimate Summon a swarm of attack drones to damage enemies.

Developer Guide

This section is designed for developers who want to modify the codebase, add new classes, or understand the underlying logic of the CS2 Warcraft Mod.

Architecture Overview

The plugin is built on CounterStrikeSharp. The core logic resides in WarcraftPlugin.cs, which initializes the following subsystems:

  • XpSystem: Manages experience gain, leveling, and skill points.
  • Database: Handles persistent storage using SQLite and Dapper.
  • ClassManager: Loads and manages WarcraftClass instances.
  • EffectManager: Handles visual effects and temporary buffs.

XP Storage Logic

Data is persisted in a SQLite database (database.db). The system uses a write-behind strategy (periodic saves) and saves on disconnect.

sequenceDiagram participant Game as Game Event participant XP as XpSystem participant RAM as WarcraftPlayer (RAM) participant DB as Database (SQLite) Game->>XP: Kill/Objective XP->>RAM: Add XP & Check Level Up RAM-->>XP: Level Up Event loop Every 60s / Disconnect RAM->>DB: SavePlayerToDatabase() DB->>DB: UPDATE raceinformation end

Ability System Logic

Abilities are event-driven. Classes inherit from WarcraftClass and register hooks to GameEvents.

Database Schema

The database consists of two main tables:

-- Stores the player's currently selected race CREATE TABLE `players` ( `steamid` UNSIGNED BIG INT NOT NULL, `currentRace` VARCHAR(32) NOT NULL, `name` VARCHAR(64), PRIMARY KEY (`steamid`) ); -- Stores progress for EACH race per player CREATE TABLE `raceinformation` ( `steamid` UNSIGNED BIG INT NOT NULL, `racename` VARCHAR(32) NOT NULL, `currentXP` INT NULL DEFAULT 0, `currentLevel` INT NULL DEFAULT 0, `amountToLevel` INT NULL DEFAULT 100, `ability1level` TINYINT NULL DEFAULT 0, ... PRIMARY KEY (`steamid`, `racename`) );

Adding a New Class

To create a new class, inherit from WarcraftClass and implement the required members.

public class MyNewClass : WarcraftClass { public override string DisplayName => "My Class"; public override Color DefaultColor => Color.Red; public override List Abilities => [ new WarcraftAbility("Passive", "Description..."), new WarcraftCooldownAbility("Active", "Desc...", 10f) ]; public override void Register() { RegisterHooks() .Hook(OnHurt); RegisterAbilities() .Bind(1, OnActiveAbility); // Binds to Ability 2 (Index 1) } private void OnHurt(EventPlayerHurt @event) { ... } private void OnActiveAbility() { ... } }
